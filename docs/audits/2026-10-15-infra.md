# Infrastructure and CI audit

Baseline 8124892, 2026-10-15. Inspected infra/*.go (excluding generated SDKs), deploy/{postgres,backup,cloud-server,host-config,ops,edge}, scripts/ci, CI workflows, acceptance orchestration. No production action or secret inspection.

## I01 High — Go string quoting used for sourced shell secrets
`infra/main.go:104-106` uses strconv.Quote. `infra/cloud_init.go:629-656` uses this for both renderPostgresEnvironment and renderBackupEnvironment. Those files are sourced by deploy/postgres/postgres-lib:8 and deploy/backup/replicate-blobs:7. Double-quoted shell assignments execute `$()` and backticks, expand `$VAR`, and do not round-trip escaped newlines. An operator-supplied password can mutate or execute commands under the job/root identity. Reproduction of exact ASCII render shape in temporary bash proved marker creation and lost secret value. Use a separate POSIX shell assignment renderer with single-quote escaping for sourced files; keep Compose serialization separate. Regression: render both env files with harmless command substitution marker, dollar, single/double quotes, backslash, tab, actual newline; source via bash in temp process, assert exact values and marker absent. Test output contains only synthetic secrets.

## I02 Medium — Backup check failure remains running
`deploy/postgres/run-pgbackrest-backup:43-51`: backup success followed by archive check error exits through set -e without heartbeat failed; database operator job row stays running. Similar unexpected failures in replicate-blobs inventory/hash commands after heartbeat running have no failed terminal state. Use EXIT handling that preserves status and records failed on unsuccessful job exits after running; never mark failed after success. Regression with fake external psql/pgbackrest/rclone processes must exercise actual scripts, backup failure/check failure/inventory/hash failure/success, assert exit code and heartbeat status order. Avoid production-only injection hooks; temporary test copy may rewrite absolute library/lock fixture paths.
