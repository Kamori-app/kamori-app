# Как пользоваться desktop DAV bridge Kamori

Статус: пользовательский и security-контракт MVP

[English version](desktop-dav-bridge.md)

Desktop bridge позволяет совместимому приложению календаря или контактов
работать с локальной копией Kamori. Это адаптер, а не основа синхронизации:
источником истины остаётся подписанный зашифрованный журнал операций.

Bridge слушает только `127.0.0.1` — адрес этого компьютера. Он недоступен с
другого устройства в Wi-Fi и не превращается в публичный облачный DAV endpoint.
Для собственных клиентов Kamori он не нужен.

## Настройка

1. Войдите в desktop Kamori и создайте либо подключите пространство.
2. На **Dashboard** выберите **Start DAV Bridge**.
3. Нажмите **Show DAV Setup**: данные подключения будут видны 60 секунд.
4. В календаре или контактах выберите custom/advanced CalDAV или CardDAV.
5. Скопируйте прямой Calendar URL или Address Book URL нужного пространства.
6. Введите показанные DAV username и отдельный DAV password.

Вход с passkey открывает `app.kamori.app` в обычном браузере и показывает один
и тот же короткий код в браузере и desktop-приложении. Подтверждайте вход,
только если коды совпадают. Токены сессии передаются через ограниченный по
времени device-authorization канал, а не через URL. Новый desktop нужно один
раз разблокировать паролем, чтобы ключ аккаунта оказался в системном хранилище;
после этого можно использовать браузерный вход.

Никогда не вводите пароль аккаунта Kamori в DAV-клиент. Случайный DAV-пароль
существует только для локального bridge и хранится в защищённом хранилище ОС.

Некоторые приложения принимают только автоматическое discovery и не позволяют
указать прямой collection URL. Совместимость обещается лишь для клиентов из
опубликованной и реально пройденной release matrix.

## Где появляется открытый текст

Облако получает только зашифрованные операции. Локальный materialized cache
защищён SQLCipher, а его ключ — средствами ОС. Но подключённый DAV-клиент может
создать собственную открытую базу, индекс, backup, уведомление или экспорт.
Эта копия уже подчиняется правилам DAV-клиента и ОС. Для максимальной изоляции
используйте собственный интерфейс Kamori без third-party DAV.

## Работа и смена пароля

Запуск bridge также запускает периодическую синхронизацию; **Sync Now** делает
цикл сразу. При остановке listener и фоновый цикл выключаются, а зашифрованный
кэш остаётся. Режим hide/minimize on close сохраняет процесс; обычный quit его
останавливает.

Если DAV-пароль раскрыт, остановите bridge, откройте **Show DAV Setup**, выберите
**Rotate Password**, подтвердите действие и обновите разрешённые DAV-клиенты.
Старый пароль перестанет работать после следующего запуска. Пароль аккаунта,
ключи шифрования и recovery kit не меняются.

Перед удалением интеграции сначала удалите DAV-аккаунт в стороннем приложении,
если хотите убрать и его открытый кэш, затем остановите bridge. Удаление DAV-
аккаунта не удаляет пространство Kamori. Удаление отдельного ресурса через
подключённый bridge создаёт подписанный tombstone после проверки revision.

MVP поддерживает защищённые прямые URL коллекций, discovery внутри коллекции,
чтение, conditional write и conditional delete. Не обещаются все опциональные
расширения CalDAV/CardDAV, scheduling и proprietary discovery flows.
