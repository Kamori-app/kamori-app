# ADR 0007: Licensing split

Status: accepted pending legal review before public source release

## Decision

Server, web, and desktop use AGPL-3.0-only. Crypto core, public protocol/SDK,
and mobile use Apache-2.0. Documentation uses CC-BY-SA-4.0. Kamori trademarks
and brand assets remain reserved.

## Consequences

Permissive core bindings avoid pulling mobile store binaries into AGPL. Future
proprietary B2B services remain process-separated or use a commercial dual
license. Substantial contributions require an approved CLA.
