# Contributing

Kamori is currently executing a pre-MVP protocol and product replacement. Small
bug reports and narrowly scoped fixes are welcome only after confirming that
they target the normative `SPEC.md` rather than superseded alpha behavior.

The project is not yet accepting substantial external code contributions. A
lawyer-reviewed contributor agreement is required before those changes can be
merged so the project can preserve its approved license split and future dual
licensing options.

When contribution intake opens, changes must:

- include tests for behavior changes;
- keep formatting, lint, and test gates green;
- avoid committing generated output without its source and regeneration step;
- avoid secrets, real user data, and unlicensed assets;
- use imperative component-scoped commit messages;
- document protocol or security consequences in an ADR.

See `CODE_OF_CONDUCT.md` for collaboration expectations and `SECURITY.md` for
private vulnerability reporting.
