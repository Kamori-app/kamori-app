# Code of conduct

Kamori contributors must communicate respectfully and professionally. Harassment,
discrimination, threats, unwanted sexual attention, deliberate intimidation,
doxxing, and sustained disruption are not acceptable in project spaces.

Technical disagreement is expected. Critique ideas and evidence, not people.
Maintainers may edit, hide, reject, or remove contributions and participation
that violate these expectations, proportionate to severity and recurrence.

Before public contribution intake, the project will publish a private conduct
reporting address, escalation path, and conflict-of-interest process. This file
is an interim policy, not a substitute for that operational process.
